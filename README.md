# NATIONAL-HEALTHCARE-ANALYTICS-DASHBOARD
INTERACTIVE POWER BI DASHBOARD ANALYZING NATIONAL HOSPITAL DATA ACROSS 10 HOSPITALS AND 6 MEDICAL CONDITIONS. TRACKS PATIENT DEMOGRAPHICS, ADMISSION TRENDS, LENGTH OF STAY, AND BILLING COSTS USING DAX AND POWER QUERY. FEATURES INTERACTIVE SLICERS FOR YEAR, HOSPITAL, AND MEDICAL CONDITION FILTERING.
